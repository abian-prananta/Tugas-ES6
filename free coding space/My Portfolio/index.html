Tentang Saya

Mengenal lebih dalam latar belakang pendidikan, nilai kerja, dan minat saya di bidang teknologi web.

Nama saya Abian Prananta, siswa berusia 16 tahun dari jurusan Rekayasa Perangkat Lunak (RPL) SMK Pelita Nusantara Plus (periode 2025 – 2026). Saya memiliki ketertarikan kuat dalam merancang antarmuka web yang bersih, responsif, dan mudah digunakan.

Selain mempelajari dasar arsitektur web seperti HTML, CSS, dan PHP, saya mengintegrasikan keterampilan Advanced AI Prompting dalam alur kerja coding harian. Keunggulan literasi digital ini membantu saya meriset modul secara cepat, memvalidasi sintaks, serta menemukan sekaligus memperbaiki bug mandiri tanpa bergantung penuh pada AI.

Dengan bekal kemahiran Bahasa Inggris level B2 (Upper-Intermediate) dan etos kerja yang mandiri, saya siap beradaptasi cepat dalam kultur industri teknologi sebagai Front-End / Web Developer Intern.
